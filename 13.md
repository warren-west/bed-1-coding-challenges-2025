## ETL Challenge
Clean a messy array of incoming customer records so it is safe to load into a clean data store.
### Input Data:
```javascript
const rawCustomerData = [
  { id: 1, email: "Alice@Example.com ", status: "active", age: 30 },
  { id: 2, email: null, status: "pending", age: 25 },
  { id: 1, email: "alice@example.com", status: "active", age: 30 },     // Duplicate ID/Record
  { id: 3, email: "bob@work.org", status: "inactive", age: "unknown" }, // Invalid data type
  { id: 4, email: "  charlie@test.com", status: "ACTIVE", age: 42 }     // Messy casing/formatting
]
```

1. **Completeness**: Drop any records where critical fields (id or email) are missing or `null`.
2. **Consistency & Formatting**: Trim whitespace from emails and convert them to lowercase. Standardize the `status` field to lowercase. Ensure age is a valid number (filter out or replace non-numeric ages like `"unknown"`).
3. **Uniqueness**: Remove duplicate records based on the `id` field (keeping the first occurrence).


### Hints:
```javascript
// .map()
// Transforms every element in a collection.
const numbers = [ 2, 0, 3, 14 ]

const doubledNumbers = numbers.map(num => {
    return num * 2

// .filter()
// Includes / excludes elements in a collection based on a TRUE / FALSE predicate.
const evenNumbers = numbers.filter(num => {
```
